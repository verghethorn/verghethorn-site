How a project runs

  1. 01

    Conversation

    You describe the task. We agree on scope, format, timing and budget range.

  2. 02

    Direction

    Script or concept, references, art direction and, for digital work, a working prototype.

  3. 03

    Production

    Film, motion, sound and code — with review points you can actually react to.

  4. 04

    Delivery

    Final files or launch, with handover notes so the work stays yours.
