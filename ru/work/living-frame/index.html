Живой кадр

Один кадр, три состояния. Кадр становится структурой, а структура — интерфейсом, которым можно пользоваться.

АвторскийРаботает

Роль
Концепция и арт-дирекшн; разработка с помощью AI
Формат
Сайт · WebGL-шейдер с запасным режимом на CSS

Задача

Показать три направления одним жестом.

Студия работает в кино, интерактиве и продуктах. Вместо трёх разделов, которые это утверждают, первый экран показывает это в одном непрерывном кадре.

Идея

Кино → структура → интерфейс.

Узкая прорезь света раскрывается в кинокадр. Сдвиньте его — и изображение читается как контуры и решётка света. Ещё раз — и объекты внутри становятся элементами интерфейса, на которые можно навести и открыть.

Как это сделано

Вручную, легко, честно.

Один фрагментный шейдер WebGL — без 3D-библиотек. Переходы между страницами — View Transitions, появление блоков — CSS-анимации по скроллу. Без WebGL кадр работает на CSS; при «уменьшении движения» просто открывается. Заголовок, навигация и контент никогда не ждут графику.
