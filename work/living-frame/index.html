The Living Frame

One frame, three states. A still becomes structure, and structure becomes an interface you can use.

Status
OriginalLive
Year
2026
Role
Concept and art direction; built with AI-assisted development
Format
Website · WebGL shader with CSS fallback

Task

Show three disciplines in a single gesture.

The studio works in film, interactive and products. Instead of three sections saying so, the first screen demonstrates it in one continuous frame.

Idea

Film → structure → interface.

A narrow slit of light opens into a cinematic frame. Shift it, and the image is read as edges and a lattice of light. Shift again, and the objects inside become interface elements you can point at and open.

How it is built

Hand-written, light, honest.

One WebGL fragment shader — no 3D library. Cross-document View Transitions between pages, scroll-driven CSS for reveals. Without WebGL the frame falls back to CSS; with reduced motion it simply opens. Headline, navigation and content never wait for graphics.
